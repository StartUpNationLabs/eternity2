# Vol-178 — STIGMA: Pheromone Adjacency Learning

Theme: ACO-inspired pheromone matrix τ[p₁, p₂, d] from corpus + winning runs; use as additive signal in beam search.

Status: `built` — used in V181 KEYRING; calibrated λ = 1e-7.

## What was attempted

1. Define τ[p₁, p₂, d] = (# times piece p₁ adjacent to p₂ in direction d across corpus boards).
2. Build at `output/vol-178/pheromone_init.json` (3MB, 120k nonzero of 262k).
3. Rust binary `v178_stigma` fork of V175: adds `pheromone_sum` to BeamState.
4. CLI: `--pheromone-file PATH --pheromone-weight λ`.

## What was measured

- Calibration: λ ∈ {1e-5, 1e-6, 1e-7, 1e-8}. λ = 1e-7 maximizes ALNS lift @ 30min.
- 36 builds × 9 scans @ λ=1e-7: top builds 452–456, similar to V175 baseline.
- Diversity preserved (multiple corner-perms across the 36 builds).
- Promoted into V181 KEYRING as the pheromone component alongside corpus prior + patch prior.

## What was kept

- `v178_stigma` Rust binary.
- Pheromone matrix `output/vol-178/pheromone_init.json`.
- λ = 1e-7 as canonical calibration.
