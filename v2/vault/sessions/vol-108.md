### T2 ✗ — Fanout-sort value ordering (REFUTED)

Built static value-ordering heuristic: per piece-rotation pr,
fanout(pr) = sum of downstream bucket sizes its bottom+right edges
would create. Sort each candidate bucket by descending fanout.

| variant      | nps (M) | max_depth |
|--------------|--------:|----------:|
| baseline     |   84-85 |       192 |
| + fanout     |   80    |       192 |

Same trajectory (depth wall at 192 is schedule-limited, not
value-order-limited). ~5% nps regression from cache perturbation.

Concept page: [[../concepts/fanout-sort-value-order]].

### T3 ✗ — BOLT post-link reordering (NOT APPLICABLE)

Researched: BOLT only supports ELF binaries (x86-64 and AArch64
**Linux**); macOS uses Mach-O. apple-m1 BOLT is fundamentally
unsupported as of late 2025. Documented in
[[../concepts/rust-perf-at-scale]].
