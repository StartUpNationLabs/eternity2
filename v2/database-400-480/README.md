# database-400-480

Curated database of Eternity II partial-solution boards with score ≥ 400 matched
edges (out of 480). All boards in this directory satisfy:

- `matched` ≥ 400 (matched-edges convention; some files may not obey all 5
  canonical hints — check `bucas_url` parameter to distinguish)
- `bucas_url` is present and points to a renderable Bucas viewer URL
- `placement` is the complete (or near-complete) 256-cell placement list

Built 2026-05-18 by `scripts/build_db_400_480.py` from 122k scratch JSONs in
`v2/output/`. **Deduplicated by bucas_url** — each unique board appears once.

## File naming

`<score>_<source-basename>_<8char-url-hash>.json`

Examples:
- `469_NEW_469_swap_pieces_234_235_at_pos_73_75_a8330e6c.json` — score 469
- `461_RECORD_461_off110_seed1_8e88ff5a.json` — score 461 record
- `458_blackwood_seed10_*.json` — score 458 strict (5/5 hint) record class

## JSON schema

Each file is normalized to:

```json
{
  "bucas_url": "https://e2.bucas.name/#puzzle=...",
  "matched": 461,
  "placement": [
    {"pos": 0, "piece_id": 1, "rotation": 3},
    ...
  ],
  "source_path": "v2/output/vol-125/records/RECORD_461_off110_seed1.json",
  "puzzle": "...",       (optional)
  "source": "...",       (optional)
  "schedule": "...",     (optional)
  "ops_preset": "...",   (optional)
  ...
}
```

## What's NOT in this DB

- **4 "480" community-corpus files** — those have no placement, no bucas_url
  (community claim records without verifiable board state). Excluded as
  requested (all entries must have a bucas_url).
- **206 boards with placement but no bucas_url** — could be regenerated by
  running the placement through `crates/export/src/bucas.rs::bucas_url`.
  Not done yet; if needed, run a Rust tool to backfill.
- **Boards below score 400** — 615 files matched score < 400.

## Bucas URL convention

Look at the URL parameter `puzzle=` to determine the convention:
- `puzzle=size_16_official_eternity` — strict canonical puzzle (5/5 hint
  compliance required)
- `puzzle=v17_alns_only` — matched-edges convention (no hint enforcement;
  used by ALNS / bf_bw pipeline)

## Source paths

The `source_path` field in each JSON points back to the original location in
`v2/output/`. Use it for traceability / re-running the producer pipeline.
