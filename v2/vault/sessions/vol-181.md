# Vol-181 — KEYRING: Patch + Pheromone + Corpus-Prior Beam

Theme: combine 3 corpus-derived signals — patch prior, pheromone, position prior — in a single beam ranker. "Keyring" because each signal is a key, and we hold them together.

Status: `built` — outperformed V175 by every metric. Discovered a new 460 basin and a new 459 basin in one sweep.

## What was attempted

1. Patch prior: enumerate all observed 2x2 patches across ≥440 corpus boards by score tier. Categorical signal: 2087 high-only, 853 neutral, 122132 low-only. Saved at `output/vol-181/patch_prior.json` (5.6MB).
2. Rust binary `v181_keyring` fork of `v178_stigma`: adds `patch_sum` to BeamState. Patch_delta uses u64 packed keys (10 bits × 4 cells).
3. CLI: `--patch-file PATH --patch-weight μ` (μ = 0.1 after calibration).
4. Sweep: 9 scans × 4 seeds = 36 builds + 30min ALNS lift on top-8.
