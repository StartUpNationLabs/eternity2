## Why these are archived

These docs served their purpose (plan or capture for a specific session) and the durable content has been absorbed into BACKLOG / INVENTIONS_BACKLOG / individual session pages / concept pages. Keeping them avoids the "15 overlapping plan docs" problem the audit identified.

To find a specific idea or invention name, prefer searching the canonical docs first. The archive is for context if a search misses.
