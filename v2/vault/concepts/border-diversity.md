# Border diversity (Las Vegas sampler + pt_e2 --pin-perimeter)

**Status**: `built` (vol-6)
**Origin**: vol-6 (response to corpus border-monoculture diagnosis)
**Files**: `crates/benchmark/src/bin/border_enumerate.rs`, `crates/bench-audit/src/bin/pt_e2.rs` (`--pin-perimeter`, `--pin-cells` flags), `scripts/border_count_estimate.py`, `output/borders/sample_100k.jsonl`

## Motivation

Vol-6 diagnosed **corpus border-monoculture**: across all community plateau boards (≥440), only 3 unique borders dominate, with 86% cell consensus. The existing CP-search starting state is structurally narrow.

## What was built

- **Las Vegas border sampler**: random border ring generation with rejection by edge-matching. **100k diverse borders in 6 seconds**.
- **Corner-tightness surrogate**: weakly predictive of border quality (vol-6/7).
- **`pt_e2 --pin-perimeter` flag**: pin a chosen border, run PT only on the 196 interior cells.
- **`--pin-cells` flag**: pin arbitrary cell set (used by [[verhaard-set-sa]] scaffold experiments).
- **`top_1000_by_corner_tightness.jsonl`**: triage output.

## Headline result

Vol-6: pinned-perimeter PT from a 453-seed reached **454/480** (byte-identical across 4 seeds — deterministic ceiling). This is still our **all-time warm-start record**.

The 454 came from a community-corpus border (not the Las Vegas sampler) + a vol-5 GA-cascade interior seed. The Las Vegas sampler proved tractability but didn't beat 449 on borders generated by it.

## Surrogate weakness

`inner-corner-tightness` surrogate (count of corner-adjacent edge pairs with constrained color matches) is only **weakly predictive**. Vol-7 tested: triaged top-1000 borders by surrogate, ran 20× budget, **never beat 449** outside the corpus borders.

→ Border quality is **not captured by static metrics alone**. The post-border interior search dominates.
