## What was built

### Vol-106

- New crate `eternity2-blackwood-fast` with row-major DFS:
  const-generic, u64 bitset, 4-table border-aware index, sentinel-
  terminated lists, `unsafe { get_unchecked }` inner loop.
- New crate `eternity2-blackwood-fast-codegen` (proc-macro) with
  `depth_dispatch_256!` for per-depth unrolling.
- Variants: `solve_raw`, `solve_blackwood`, `solve_blackwood_par`,
  `solve_blackwood_par_offset`, `solve_blackwood_unrolled_256`,
  `solve_blackwood_unrolled_256_v17a_const`.
- Multi-thread rayon with bucket-shuffle seeds.
- Best-board recovery + scoring (`SearchStats.best_score`,
  `score_board`).
- Pipeline support via `--dump-partial` + `alns_only --cp-board`.
- `bf_similarity` measurement bin.
- `vanilla_v2` bin: vanilla DFS with the same architectural patterns.
- `scripts/build_pgo.sh` reproducible PGO build.
- `scripts/build_release.sh` one-command PGO build for the three
  production bins.

### Vol-107

## Vol-109+ candidates

In approximate decreasing prior-of-payoff:

1. **Oracle-aware ALNS repair** (T1 continuation): destroy σ-cycle
   AND force-place oracle pieces in halo, then repair the cycle's
   interior. Could unlock basins. Multi-day.
2. **Beam-search engine**: K=8 beam-width DFS variant. May find
   trajectories DFS misses. 1-2 days.
3. **Cross-machine bench** (intel/M2): needs cross-linker or actual
   Linux access. 2-4 hours if Linux accessible; 8+ otherwise.
4. **Per-schedule const tables for v15** (mirror of T1 for the
   affine-remapped 469 schedule). 1-2 hours; small expected win.
5. **σ-cycle apply-as-ALNS-op** (vol-18 `apply_cycle` as
   DestroyOp): bypass barrier-crossing in one step. The vol-18 work
   already characterised this as ineffective in isolation; might
   compose with other ops. 1-2 days.
