## Open at close

🎯 **NEW from-scratch ceiling: 456/480** with K=4096 + PRIOR + path-dedup-4.

**Prior matrix** built from 938 high-score (≥440) DB boards:
- 30,416/65,536 (piece, pos) pairs have ≥1 occurrence.
- Top 5: canonical hint pieces at hint positions (70%, 68%, 68%, 51%, 47%).
- Diffuse middle: 29,900 (piece, pos) pairs with 0-49 occurrences.

**Results table (canonical 16×16/22 from scratch):**

| Config | Best | Time |
|--------|------|------|
| V151 K=1024 (plain) | 453 | 18s |
| V155 K=1024 + prior tiebreak | 454 | 23s |
| V155 K=1024 + prior alpha=0.001-0.1 | 454 | 22-31s |
| V151 K=4096 (plain, no path-dedup) | 449 | 85s |
| V151 K=16384 (path-dedup-8, no prior) | 455 | 21min |
| **V155 K=4096 + prior + path-dedup-4** | **456** | 117s |
| V155 K=8192 + prior + path-dedup-8 | (running) | ~5min |

The K=4096 + prior + path-dedup-4 config dominates: 7 points better
than plain K=4096, in similar wallclock. **+8 over V150 random sweep
(408 → 456)**, **+3 over V151 ceiling (453 → 456)**.

**Why the lift**: at K=4096 the beam has many ties that path-dedup
keeps diverse. The prior breaks ties in favor of "common" piece-
positions, biasing exploration toward likely-good basins.
