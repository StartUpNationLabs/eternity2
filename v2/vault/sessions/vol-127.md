**Theme**: Compile the canonical E2 piece set into rigid molecules

## The math (terse)

For each color $C \in \{1, \ldots, 22\}$, let $k_C$ = number of
(piece, side) occurrences of color $C$ across the 256-piece canonical
set. Canonical distribution: 5 rare colors at 24 occurrences, 5
medium at 48, 12 common at 50. (sum = 5·24 + 5·48 + 12·50 = 960.)

Each color $C$ appears on $k_C$ piece-sides. In any solution, edges
internally match → $k_C / 2$ matched-adjacency pairings of pieces
through color $C$. The number of pairings is

$$
\text{pairings}(C) = \frac{k_C!}{(k_C/2)! \cdot 2^{k_C/2}} \cdot 2^{k_C/2}
                   = \frac{k_C!}{(k_C/2)!}
$$

after accounting for which (piece, side) pairs with which. For
$k_C = 24$ (rare) this is still astronomically large in absolute
terms, BUT the *constraint product* across multiple rare colors at the
SAME piece is what reduces feasibility.

The trick: if piece $P$ has 4 side colors $(C_1, C_2, C_3, C_4)$ all
rare, then $P$ participates in 4 rare-color pairings simultaneously,
and the constraint product (intersection) is often empty or
near-empty. When near-empty, $P$'s neighbour-pairs become forced
(unique up to rotation choice).

## Binding items (3 max)

1. **`canonical_color_inventory`**: precompute for canonical E2 the
   list of (piece, side, color, rotation-orbit) tuples. Output: a
   table that says "color $C$ has $k_C$ occurrences across this set
   of (piece, rotation-orbit) pairs".
2. **`rare_color_forced_pairings`**: for each rare color $C$ (the 5
   smallest $k_C$), enumerate ALL legal pairings. For each pairing,
   compute the implied piece-pair forced edges.
3. **`molecule_chaining`**: iterate to fixed point. Start with the
   strongest forced pairings; absorb them as welded macro-tiles.
   Iterate. Measure molecule statistics: how many pieces end up in
   molecules ≥ size 2? size 3? size 4?
