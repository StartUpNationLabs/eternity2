# Vol-209 — ISENTROPE: entropy theory of E2's piece-alphabet

**Theme** (user-chosen "new construction paradigm", then "characterization →
understanding → tools; math/proofs + experiments"): adapt the 2026 Canfora-Cedeño
Wang-tiling statistical-mechanics framework to canonical E2. Delivered a THEOREM, a
quantified AREA-LAW, a scalable width-16 instrument, and a structural marginals
result — together a unified, quantified characterization of *why* E2 is hard.

## What was attempted
- Compute the tiling-count entropy S_Γ(n)=log W_Γ(n) of E2's piece-alphabet, two
  variants: A reusable (color grammar) / B distinct (true-E2 scarcity).
- Prove the entropy-density limit exists & is positive (Perron-Frobenius + Fekete).
- Reach the TRUE width 16 (exact transfer dies at width 5) via χ-truncated MPS.
- Compute per-cell placement marginals at full width (new solver handle?).

## What was built (all validated)
- `crates/bench-audit/src/bin/isentrope_count.rs` — exact counts (broken-profile DP,
  packed-u64 state), row-transfer power-iteration entropy density, scarcity-ratio
  sampler. Validated: n=2 reusable 4,550,669 & distinct 4,059,952 vs Python brute;
  self-consistency h(1)=1-D row entropy=1.66447.
- `crates/peps/src/mps_proper.rs` + bins `isentrope_peps`, `isentrope_marginals` —
  PROPER χ-truncated boundary MPS (the existing `peps/mps.rs` materialized K^16 and
  crashed; this keeps a true MPS). Reaches width 16. `cell_marginals` (top/bot
  environments + lenv/renv) gives all-cell marginals. Validated EXACTLY vs
  brute-force on 4×4 (every cell, 3 decimals); χ-truncation converges from below
  (4×4 locks to exact 370; 6×6 → 99.6% at χ=64).

## What was measured / kept (the results)
1. **THEOREM** ([[MATH_NOTES_2026-06-10_isentrope_entropy_theorem]]): E2's color
   grammar has a positive topological entropy density h∞ = lim log λ_n / n, with
   0 < h∞ ≤ log₁₀λ_H = 1.6645, **h∞ ≈ 0.67 log₁₀/cell** (free-interior). h(n) monotone
   decreasing (= Fekete signature, measured: 1.66→1.05→0.84→0.74). λ_H=λ_V=46.18.
2. **Distinctness AREA-LAW**: ρ(n)=W_distinct/W_reusable measured 1.0, 0.89, 0.65,
   0.33 (n=1..4) → **ρ(n) ≈ exp(−0.085 n²)** (extensive in AREA). ρ<10⁻³ at ~81 cells.
3. **The wall, explained**: ρ-collapse scale (~80 cells) = σ-cycle scale = row-9
   construction wall = 112-cell exact window = irreducible-hard-region. ONE quantified
   mechanism: rich grammar (positive entropy) vs area-law distinctness cost → legal
   fraction → 0 at ~80 cells. **Hardness = area-law cost of distinctness, not matching.**
4. **Width-16 MPS entropy**: W_grammar(16×16) ≈ **10^108.78**, density 0.42491/cell
   (real bordered board; never computed before; below free-interior 0.67 because the
   rim is constrained). Converged χ=16→32.
5. **All-cell marginals (real E2, χ=6)**: **BIMODAL** — boundary 60 cells mean n_eff
   48 (corners ~4, near-forced); **interior 196 cells mean n_eff 749 of 784 (95.5%) —
   almost perfectly uniform.** No local interior placement preference. Strongest
   confirmation of [[lattice-forced-chains]] from the entropy side. Time curve:
   cost ~K⁴ (K=colors), E2 K=23 worst case.

## What was refuted / negative (precisely scoped)
- Marginals give **no new interior solver signal** (interior 95.5% uniform). The
  grammar is structureless in the bulk; information is only at the boundary (already
  known constrained). A clean negative for "marginal-guided value ordering."
- (Not a refutation of the tool — the contractor is validated; the *finding* is that
  the interior carries no exploitable local bias.)
