# Vol-183 — SEMAPHORE: Per-Row Chain-DP

Theme: build row-by-row using exact chain-DP / bipartite matching against pieces remaining, picking the optimal row given N-edge constraint from row above.

Status: **refuted** — row-10 piece-starvation wall.

## What was attempted

1. Python PoC: at row $r$, given N-edge color sequence from row $r-1$'s S-edges, run bipartite matching to find piece-rotation assignment to columns 0..15 maximizing horizontal matches subject to N-edge constraint.
2. Iterate row 0 → 15.
3. Variant: beam K=32 over (row, used-pieces) states.

## What was measured

| Row | PoC | Beam K=32 |
|---|---|---|
| 0 | OK (border) | OK |
| 1–5 | OK | OK |

| Score | 294/480 at row 10 | similar |

## What was refuted

- "Per-row chain-DP can build to 460+ without lookahead" — refuted at row 10. Greedy row commit makes early pieces unrecoverable; beam K=32 doesn't help because all top-K rows pull from the same promising piece pool.

## What was kept

- PoC code (small, demonstrates the failure clearly).
- Lesson: row-building needs JOINT-row foresight (bidirectional or full beam-search like V155/V175/V181).
