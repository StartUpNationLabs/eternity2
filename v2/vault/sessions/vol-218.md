distinctness-aware LOWER BOUND certificate (b\* > B). BANDSAW =
exact solver within its tractable radius (b\* ≲ 7 at 10×10) + an
anytime exact-LB ladder beyond it. The relax floor cannot do this —
M1 says it is fiction precisely where this matters. M2 exactness
gate now runs on a CONTROLLED b\*-graded family (canonical-prefix
frontier corruptions, 0-6 columns) + blind entries get [LB, greedy]
brackets.

column-state tables (backward-over-rows formulation; charges attach
to OUTPUT axes so only point reads + A/B/C/D class mins are needed);
selftests: suffix floor ≡ relax floor; suffix prune changes no
counts; prune only removes nodes.
