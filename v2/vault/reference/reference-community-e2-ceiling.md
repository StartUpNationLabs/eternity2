# Reference — community E2 ceiling

Mirror of memory `reference_community_e2_ceiling`. Authoritative content lives in [[basin-mcgavin-469]] and [[community-corpus]].

## TL;DR

**Verified canonical 5-clue Monckton E2 ceiling: 469/480** by Peter McGavin (2020-09-09) using Joshua Blackwood's solver on "a couple of hundred cores for a few days". groups.io message 172011298. All 256 pieces in IDs 1..256.

## Watch out for confounds

- McGavin's "480" (2023-10-09): mixed Clue1 + Clue2 piece sets.
- McGavin's 471 / Razvan 480: Joe's 17-color + Brendan's 16×16 variants.
- 3 boards labelled 470 (Blackwood 2021, capiman 2021, onesmallstep 2025): Blackwood-unframed/0-clue.
- "Takahashi 468 (2009)" is unverified folklore.
- reinout_ Discord "471/480" 2026-01: goal statement, not achievement.
